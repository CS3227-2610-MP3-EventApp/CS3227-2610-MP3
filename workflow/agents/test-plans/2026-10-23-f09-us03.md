## Assumptions and limits (unknown marker key and DOM)
- r15 does not fix DOM labels or the localStorage key. Tests use tolerant role/name regexes: entries as checkboxes named by product; action type as radios (/purchase|cart/, /quotation/); fields /recipient/ and /request text|message|details/; buttons /revis/, /approve/, /simulat/, /cancel/, /create/, "Sign out"; a hidden control counts as disabled; an open/review action for detail is tolerated; approval/cancel may use a dialog or window.confirm.
- The marker is assumed to be one localStorage JSON value with actorId/proposalId/proposalRevision; the test discovers its key from storage rather than naming it. An implementation using several keys or non-JSON would need a reviewed test-change request, not a silent edit.
- Fixed texts matched by regex (/not permitted/, /unavailable/, /sign in/, /could not be completed/, /cannot be accepted/, /data error|invalid data|cannot be shown|malformed/, /Known-items subtotal/, /all item prices are unknown/, /unverified/, /not (yet )?simulated/); history order uses "Revision N" text. If spec wording is later fixed these should be tightened.
- Snapshot payload `listedPrice` is modelled as an object; F10 does not enumerate it. Fake digests are 64 hex characters.
- Synthetic data only. Cases were designed from r15, not a guessed implementation, but the stateful fake encodes the F10 wire shapes seen in `backend/app/external_actions/schemas.py`.

- Success, rejection, boundaries, failure/state preservation: covered (T07-T15, T19-T45).
- Wrong user/business/role, draft/private data: roles null/attendee/organiser, foreign participation/foreign rows, 401/403/404 (T03, T40-T46); inactive membership relies on backend baseline.
- Stale revisions, concurrency, retries/dedup: stale_source, revision_conflict, fresh keys, in-flight, cross-tab (T09, T29-T35); true DB concurrency is backend.
- Persistence/restart, migrations, real producer/consumer: marker across reload (T34); real integration deferred.
- AI schema/evidence/injection/fallback: N/A for this story (no AI), except inert source/user text (T17).
- Accessibility/usability: partial (T50); layout/reflow manual.
- Expected results follow approved r15, not implementation: yes by design; independent review pending.
- Tests can detect a wrong implementation: not yet proven; reviewers should mutate/review.
