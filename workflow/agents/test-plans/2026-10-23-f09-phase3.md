## Harness and seams

Agreed technical test seams with orchestrator/implementer: `app.external_actions.service.utcnow()` returns aware UTC; `simulate(payload)` returns `(outcome, reasonCode)` and is internal only. No client may select failure state or time. These isolate exact time boundaries and internal simulation failure from network behavior. PostgreSQL audit failure is a real transactional failure, not a mocked commit.

Imports reuse protected fixtures from `test_business_applications`, `test_promotional_concepts`, `test_supplier_research`, plus `conftest.py`/`reset_guard.py`; dependency tests are unchanged. Production modules are not imported until after create-route assertions, allowing absent-route reds rather than collection errors.

Exact focused command from `backend/`, with `DATABASE_URL` loaded privately from ignored backend `.env`, `TEST_DATABASE_URL=postgresql+psycopg://eventapp_test:eventapp_test@127.0.0.1:5433/eventapp_test`, `EVENTAPP_ALLOW_TEST_DB_RESET=true`, `PYTHONPATH` set to backend:

` .venv\Scripts\python.exe -m pytest tests/test_external_actions.py -q `

Broader command: `.venv\Scripts\python.exe -m pytest tests unit_tests developer_checks -q` using the same guarded environment. Run PostgreSQL suites serially because the shared fixture truncates the isolated database.

## Coverage limits and deferred checks

- Fresh TestClient and fresh Python subprocess retrieve the same persisted receipt without reseeding. PostgreSQL host restart is not tested.
- Exact immutable revision-history shape beyond current detail is not specified. Developer/verifier inspect history storage without inventing response keys.
- Synthetic unsafe source/deletion/owner/seller faults are executable; independent source inspection complements network tripwires and checks corrupted stored digest handling. No claim of exhaustive lexical address or concurrency interleaving coverage.
- Actual organiser consumer, Phase 4 editor, real email/order/payment, UI/accessibility, deployment and production isolation are out of scope. No provider integration is claimed.
- Retention means no cleanup/deletion API in this slice; long-term operational retention is not time-travel tested.
- No AI output generation occurs in this service; injection text remains inert and network tripwire plus explicit registry tests bound approval behavior.
