## Agreed wire contract

`POST /api/v1/organiser/events/{event}/programme-items/{item}/changes` accepts complete current editable programme fields plus strict expectedRevision, confirmed=true, optional reason (maximum1000). `/cancel` requires expectedRevision, confirmed=true and trimmed reason1..1000. Returns latest ProgrammeItem with lastChangeId/cancellationReason/cancelledAt. Stale/repeated cancellation409, no-op422. GET `/changes` returns paginated items/total/limit/offset; each transition has id,itemId,fromRevision,toRevision,oldFacts,newFacts,reason,changeType,occurredAt. Immutable snapshots, transition and success audit commit atomically. Published/cancelled attendee list/detail show latest snapshot; overlap allowed.

Announcement create POST `/announcements` {changeId,body}201; edit PATCH `/{id}` {expectedRevision,body}; owner-private GET list/detail; POST `/{id}/preview` {expectedRevision} returns previewId,announcementId,revision,body,expiresAt; POST `/{id}/publish` {previewId} returns published announcement. Draft response id,eventId,changeId,body,revision,state,createdAt,updatedAt,publishedAt,sourceFacts; body plain text trimmed1..3000. Repeat valid preview idempotent. Preview binds exact actor/body/source/draft revision for15minutes. Same successful preview replay returns same published record after expiry with fresh authorisation; competing different draft publications for one change conflict409. Attendee `/api/v1/attendee/events/{event}/announcements` list/detail exposes published only, no private owner/audit/recipient fields.

F02 absent: actual notification producer/accepted-itinerary integration explicitly blocked; no fabricated accepted-plan tables or empty-recipient success. Attendee notification list/detail/read routes return structured503. Domain change remains available with recipientSnapshotStatus=blocked_f02 under default disabled planning integration. Enabling planning without registered real provider fails before mutation. Full RD05 release evidence remains blocked.
