Built for three perspectives

Everyone sees what matters to them.

01

Attendees

Browse published activities, filter the programme, review accessibility information and build a personal plan.

  • Event-local date and time display
  • Accessibility-aware planning
  • AI suggestions that remain optional
02

Organisers

Maintain programme facts, constrain activity times to the event window and communicate changes clearly.

  • Revisioned programme publishing
  • Change and cancellation workflows
  • Private drafts and explicit approval
03

Businesses

Submit applications and follow the formal review and decision process for event participation.

  • Role-specific workspace
  • Application status visibility
  • Secure authenticated access

Human-led, AI-assisted

AI should support a decision, not silently make one.

EventApp treats AI output as an untrusted suggestion. Jobs are bounded by ownership, revisions, quotas and validation. Organisers review private announcement drafts before publication, and attendees choose whether to save a current itinerary suggestion.

AI features require the appropriate synthetic-data configuration. If a provider fails or returns stale output, the existing application state is preserved and manual workflows remain available.
